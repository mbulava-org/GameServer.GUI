## ?? Database Integration

### Data Flow

```
User Input (UI)
  ?
GameTypeEditorDialog.razor
  ?
IGameTypeApi.CreateAsync() / UpdateAsync()
  ?
GameTypeController
  ?
IGameTypeRepository.CreateAsync() / UpdateAsync()
  ?
GameServerDbContext (EF Core)
  ?
SQLite Database (./data/gameserver.db)
```

### Tables Used

1. **GameTypes** - Basic game type info
2. **Ports** - Port mappings
3. **Volumes** - Volume mounts
4. **DefaultSettings** - Environment variables
5. **ExtendedMetadata** - TTY and advanced settings
6. **SettingsMetadata** - Setting presentation rules
7. **PortValidation** - Port validation rules (future)
8. **PortRelationships** - Port relationship rules (future)
